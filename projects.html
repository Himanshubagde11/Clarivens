Flagship Enterprise Platform · Cloud Data & Automation

Clarivens Inventory Intelligence — Azure Retail Analytics Platform

An enterprise-grade, end-to-end retail data platform that automates multi-source ingestion, data quality validation, warehouse transformation, and business intelligence. Architected for a multi-format retail group operating 36 physical stores across 9 Indian states, the platform ingests 178,000+ transactional and inventory records, enforces a 12-rule Python automated data-quality gate, orchestrates incremental loading into an Azure SQL dimensional star schema, and powers an executive 6-page Power BI suite.

01 / Challenge

Retail transactional and inventory data arrived fragmented across POS registers, flat supplier spreadsheets, and vendor APIs, creating blind spots in stockout risks, overstocked capital, and margin erosion.

02 / Cloud Architecture

Engineered an automated Azure Data Factory v2 pipeline extracting multi-source records into Azure Data Lake Storage Gen2, with orchestrated pipeline triggers and automated retry policies.

03 / Data Quality Gate

Implemented a 12-rule automated Python audit gate validating referential integrity, range bounds, negative stock flags, and date sanity, achieving a 99.9% clean-data pipeline score.

04 / Executive BI Suite

Built a 6-page interactive Power BI suite with 25+ specialized DAX measures tracking Sell-Through Rates, GMROI, Stockout Priority Matrix, and supplier delivery variances.

Flagship Enterprise Analytics · Data Warehouse, ML & BI Engineering

VEYRA — E-Commerce Sales Analytics & Customer Segmentation

An end-to-end, enterprise-grade data analytics platform designed to Senior Data Analyst and BI Engineer standards. Features a fully operational, mathematically reconciled analytics pipeline spanning 2,099,963 order lines across 100,000 customer accounts. Engineered a Kimball star schema in Microsoft SQL Server with Columnstore indexing, automated Python 20-point data quality auditing, Scikit-Learn behavioral ML clustering (RFM & K-Means K=5), explainable customer churn and CLV modeling, an analyst Excel workbook, and a 7-page C-suite Power BI reporting suite.

01 / Star Schema & Columnstore

Architected a high-performance Kimball data warehouse in SQL Server (DimCustomer, DimProduct, DimDate, DimLocation, DimPayment, FactSales, FactReturns). Implemented a Nonclustered Columnstore Index (NCCIX_FactSales) achieving 90%+ compression and accelerating aggregations by >20x.

02 / Automated Quality Gate

Built an automated Python audit framework executing 20 structural, referential, and mathematical checks across 100k accounts, guaranteeing 100% financial accuracy across $941.6M in net sales and $371.9M in gross profit (39.50% margin).

03 / RFM & K-Means Clustering

Applied 1–5 quintile RFM scoring and Scikit-Learn K-Means (K=5): revealed that 28.4% of customers (“Champions”) drive 72.6% ($683.6M) of revenue, while isolating 15,498 high-churn accounts representing $50,940,454.53 in Revenue at Churn Risk.

04 / 7-Page Power BI & Excel Suite

Engineered an executive dark/orange Power BI platform with 25+ DAX measures (VAR/RETURN) and customer 360 drill-through, paired with a 7-sheet Microsoft Excel financial model utilizing dynamic XLOOKUP, SUMIFS, and scenario tables.

Public Health Analytics · Time-Series & Epidemiological Modeling

Global Health Trajectory Analysis & Epidemiological Trend Modeling

A rigorous epidemiological data engineering and visualization study exploring the worldwide transmission dynamics of the COVID-19 pandemic. Collected, harmonized, and analyzed over 5,000,000 multi-national records from the World Health Organization (WHO) and Johns Hopkins University (CSSE) repositories to uncover transmission velocities, regional recovery differentials, and rolling mortality patterns across 180+ sovereign jurisdictions.

01 / Ingestion & Cleansing

Aggregated raw time-series feeds from global public health registries, reconciling divergent country reporting formats, zero-value filling, and retroactive corrections.

02 / Moving Average Modeling

Implemented 7-day trailing moving averages to neutralize weekend reporting fluctuations, revealing underlying wave acceleration trajectories and inflection milestones.

03 / Case Fatality Indices

Calculated dynamic Case Fatality Rates (CFR) and testing-positivity ratios across demographic tiers and geographic regions to assess health system resilience.

04 / Visual Communication

Rendered multi-dimensional publication-ready heatmaps, comparative log-scale wave curves, and choropleth visualizations documented within interactive Jupyter Notebooks.

Cloud AI Engine · Machine Learning & Generative Intelligence

Clarivens Automated Analytics Workspace & ML Inference Engine

The core computational engine powering the Clarivens client portal. This system provides an automated, zero-ETL data analysis workflow: users upload CSV, Excel, or JSON datasets, and the engine automatically profiles statistical distributions, performs memory-safe data cleansing, benchmarks predictive machine learning models, and leverages Google Gemini 2.5 Flash to synthesize executive business insights without data hallucination.

01 / Security Gate

Magic-byte MIME verification, strict format allowlisting (CSV, XLSX, JSON), size limits (50MB), and UUID file path abstraction preventing directory traversal attacks.

02 / Automated Profiling

Instantaneous statistical inferencing determining column types, missingness, unique value cardinality, and distribution metrics within a sub-second sampling window.

03 / AutoML Target Heuristic

Intelligent target column heuristic detecting business metrics (revenue, sales, churn) and training RandomForest Regressors/Classifiers with out-of-sample benchmarking.

04 / Generative Strategic AI

Transmits aggregated statistical summaries (never raw records) to Google Gemini 2.5 Flash, enforcing strict Pydantic JSON schemas for structured, non-hallucinated findings.
